# 📚 Unidad 1: Análisis de lógica combinacional con diseño clásico
## Semana 2: Álgebra de Boole y formas canónicas

## 1. Relación entre Circuitos y Expresiones Booleanas

Un circuito combinacional y una expresión algebraica booleana representan exactamente la misma información.

| Elemento del Circuito | Símbolo / Operación Booleana | Descripción |
| :--- | :--- | :--- |
| **Cable de entrada** | Variable (`A`, `B`, `C`) | Representa las señales de entrada. |
| **AND** | Producto (`·`) | Operación lógica AND. |
| **OR** | Suma (`+`) | Operación lógica OR. |
| **NOT** | Complemento (`'`) | Inversión o negación de la señal. |
| **Salida** | Valor de la expresión (`Y`) | Resultado lógico del circuito. |

> ⚙️ **Precedencia de operadores:** Primero se evalúa el NOT (`'`), luego el AND (`·`) y finalmente el OR (`+`).

---

## 2. Álgebra de Boole: Postulados y Teoremas

El álgebra de Boole trabaja sobre el conjunto `{0, 1}` mediante tres operaciones fundamentales: suma (`+`), producto (`·`) y complemento (`'`).

### Postulados de Huntington
| Postulado | Forma OR (`+`) | Forma AND (`·`) - Dualidad |
| :--- | :--- | :--- |
| **Identidad** | `X + 0 = X` | `X · 1 = X` |
| **Complemento** | `X + X' = 1` | `X · X' = 0` |
| **Conmutativa** | `X + Y = Y + X` | `X · Y = Y · X` |
| **Distributiva** | `X · (Y + Z) = (X · Y) + (X · Z)` | `X + (Y · Z) = (X + Y) · (X + Z)` |

*Nota de dualidad:* Intercambiando los operadores `+` por `·` y los elementos `0` por `1` (sin alterar las variables), la identidad resultante sigue siendo válida.

### Teoremas Clave de Simplificación
- **Elemento nulo:** `X + 1 = 1` | `X · 0 = 0`
- **Idempotencia:** `X + X = X` | `X · X = X`
- **Involución:** `(X')' = X`
- **Absorción:** `X + X·Y = X` | `X · (X + Y) = X`
- **Absorción del complemento:** `X + X'·Y = X + Y` | `X · (X' + Y) = X · Y`
- **Adyacencia:** `X·Y + X·Y' = X` | `(X + Y) · (X + Y') = X`
- **Consenso:** `X·Y + X'·Z + Y·Z = X·Y + X'·Z`

## 3. Leyes de De Morgan

Permiten transformar operaciones de suma negada en productos negados y viceversa, "rompiendo la barra y cambiando el operador".

- **Para dos variables:** 
  - `(A · B)' = A' + B'`
  - `(A + B)' = A' · B'`
- **Generalización (n variables):** 
  - `(A + B + C + ...)' = A' · B' · C' · ...`

## 4. Minitérminos, Maxitérminos y Formas Canónicas

Cada función lógica se puede expresar de forma única a partir de su tabla de verdad utilizando minitérminos o maxitérminos.

- **Minitérmino (`mᵢ`):** Es un producto (`·`) donde la variable aparece sin complementar si vale `1`, y complementada si vale `0`. Representa las filas donde la función vale `1`.
- **Maxitérmino (`Mᵢ`):** Es una suma (`+`) donde la variable aparece sin complementar si vale `0`, y complementada si vale `1`. Representa las filas donde la función vale `0`.

### Formas Canónicas
- **SOP (Sum of Products / Suma de Productos):** Se construye uniendo con operadores OR (`+`) todos los minitérminos donde la salida `F = 1`. Se denota como `F = Σm(...)`.
- **POS (Product of Sums / Producto de Sumas):** Se construye uniendo con operadores AND (`·`) todos los maxitérminos donde la salida `F = 0`. Se denota como `F = ΠM(...)`.

---

## 5. Criterio de Elección: ¿SOP o POS?

La elección entre utilizar una forma SOP o POS depende de la optimización del circuito físico:
1. **Pocos unos en la tabla:** Conviene **SOP** porque genera menos términos.
2. **Pocos ceros en la tabla:** Conviene **POS** porque genera menos términos.
3. **Disponibilidad tecnológica:** 
   - Si solo se dispone de compuertas **NAND**, la forma SOP optimiza el diseño (NAND-NAND, ej. chip 7400).
   - Si solo se dispone de compuertas **NOR**, la forma POS optimiza el diseño (NOR-NOR, ej. chip 7402).

---

## 6. Ejemplo Práctico: Alarma de 3 Sensores

Para diseñar una alarma que se active (`F = 1`) cuando al menos dos de tres sensores (Puerta `A`, Ventana `B`, Movimiento `C`) estén activos:

1. **Forma Canónica SOP:** 
   `F = Σm(3, 5, 6, 7) = A'BC + AB'C + ABC' + ABC`
2. **Proceso de Simplificación Algebraica:**
   - Aplicando la propiedad de idempotencia (`ABC = ABC + ABC + ABC`) y agrupando términos adyacentes:
     - `A'BC + ABC = BC(A' + A) = BC`
     - `AB'C + ABC = AC(B' + B) = AC`
     - `ABC' + ABC = AB(C' + C) = AB`
3. **Expresión Simplificada Final:**
   `F = AB + AC + BC`

*Ahorro en hardware:* La versión canónica requiere circuitos integrados complejos (ej. múltiples compuertas e inversores, evaluando 4 circuitos integrados), mientras que la versión simplificada reduce drásticamente el costo físico a solo 2 circuitos integrados (`7408` y `7432`).
