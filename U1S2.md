## 1. Relación entre Circuitos y Expresiones Booleanas

Un circuito combinacional y una expresión algebraica booleana representan exactamente la misma información[cite: 34].

| Elemento del Circuito | Símbolo / Operación Booleana | Descripción |
| :--- | :--- | :--- |
| **Cable de entrada** | Variable (`A`, `B`, `C`)[cite: 34] | Representa las señales de entrada[cite: 34]. |
| **AND** | Producto (`·`)[cite: 34] | Operación lógica AND[cite: 34]. |
| **OR** | Suma (`+`)[cite: 34] | Operación lógica OR[cite: 34]. |
| **NOT** | Complemento (`'`)[cite: 34] | Inversión o negación de la señal[cite: 34]. |
| **Salida** | Valor de la expresión (`Y`)[cite: 34] | Resultado lógico del circuito[cite: 34]. |

> ⚙️ **Precedencia de operadores:** Primero se evalúa el NOT (`'`), luego el AND (`·`) y finalmente el OR (`+`)[cite: 34].

## 2. Álgebra de Boole: Postulados y Teoremas

El álgebra de Boole trabaja sobre el conjunto `{0, 1}` mediante tres operaciones fundamentales: suma (`+`), producto (`·`) y complemento (`'`)[cite: 36].

### Postulados de Huntington
| Postulado | Forma OR (`+`) | Forma AND (`·`) - Dualidad |
| :--- | :--- | :--- |
| **Identidad** | `X + 0 = X`[cite: 36] | `X · 1 = X`[cite: 36] |
| **Complemento** | `X + X' = 1`[cite: 36] | `X · X' = 0`[cite: 36] |
| **Conmutativa** | `X + Y = Y + X`[cite: 36] | `X · Y = Y · X`[cite: 36] |
| **Distributiva** | `X · (Y + Z) = (X · Y) + (X · Z)`[cite: 36] | `X + (Y · Z) = (X + Y) · (X + Z)`[cite: 36] |

*Nota de dualidad:* Intercambiando los operadores `+` por `·` y los elementos `0` por `1` (sin alterar las variables), la identidad resultante sigue siendo válida[cite: 36].

### Teoremas Clave de Simplificación
* **Elemento nulo:** `X + 1 = 1` | `X · 0 = 0`[cite: 37]
* **Idempotencia:** `X + X = X` | `X · X = X`[cite: 37]
* **Involución:** `(X')' = X`[cite: 37]
* **Absorción:** `X + X·Y = X` | `X · (X + Y) = X`[cite: 37]
* **Absorción del complemento:** `X + X'·Y = X + Y` | `X · (X' + Y) = X · Y`[cite: 37]
* **Adyacencia:** `X·Y + X·Y' = X` | `(X + Y) · (X + Y') = X`[cite: 37]
* **Consenso:** `X·Y + X'·Z + Y·Z = X·Y + X'·Z`[cite: 37]

## 3. Leyes de De Morgan

Permiten transformar operaciones de suma negada en productos negados y viceversa, "rompiendo la barra y cambiando el operador"[cite: 39].

* **Para dos variables:** 
  * `(A · B)' = A' + B'`[cite: 39]
  * `(A + B)' = A' · B'`[cite: 39]
* **Generalización (n variables):** 
  * `(A + B + C + ...)' = A' · B' · C' · ...`[cite: 39]

## 4. Minitérminos, Maxitérminos y Formas Canónicas

Cada función lógica se puede expresar de forma única a partir de su tabla de verdad utilizando minitérminos o maxitérminos[cite: 41, 55].

* **Minitérmino (`mᵢ`):** Es un producto (`·`) donde la variable aparece sin complementar si vale `1`, y complementada si vale `0`[cite: 41]. Representa las filas donde la función vale `1`[cite: 41, 42].
* **Maxitérmino (`Mᵢ`):** Es una suma (`+`) donde la variable aparece sin complementar si vale `0`, y complementada si vale `1`[cite: 41]. Representa las filas donde la función vale `0`[cite: 41, 43].

### Formas Canónicas
* **SOP (Sum of Products / Suma de Productos):** Se construye uniendo con operadores OR (`+`) todos los minitérminos donde la salida `F = 1`[cite: 42]. Se denota como `F = Σm(...)`[cite: 42].
* **POS (Product of Sums / Producto de Sumas):** Se construye uniendo con operadores AND (`·`) todos los maxitérminos donde la salida `F = 0`[cite: 43]. Se denota como `F = ΠM(...)`[cite: 43].

---

## 5. Criterio de Elección: ¿SOP o POS?

La elección entre utilizar una forma SOP o POS depende de la optimización del circuito físico[cite: 45]:
1. **Pocos unos en la tabla:** Conviene **SOP** porque genera menos términos[cite: 45].
2. **Pocos ceros en la tabla:** Conviene **POS** porque genera menos términos[cite: 45].
3. **Disponibilidad tecnológica:** 
   * Si solo se dispone de compuertas **NAND**, la forma SOP optimiza el diseño (NAND-NAND, ej. chip 7400)[cite: 45].
   * Si solo se dispone de compuertas **NOR**, la forma POS optimiza el diseño (NOR-NOR, ej. chip 7402)[cite: 45].

## 6. Ejemplo Práctico: Alarma de 3 Sensores

Para diseñar una alarma que se active (`F = 1`) cuando al menos dos de tres sensores (Puerta `A`, Ventana `B`, Movimiento `C`) estén activos[cite: 47]:

1. **Forma Canónica SOP:** 
   `F = Σm(3, 5, 6, 7) = A'BC + AB'C + ABC' + ABC`[cite: 42, 48]
2. **Proceso de Simplificación Algebraica:**
   * Aplicando la propiedad de idempotencia (`ABC = ABC + ABC + ABC`) y agrupando términos adyacentes:
     * `A'BC + ABC = BC(A' + A) = BC`[cite: 48]
     * `AB'C + ABC = AC(B' + B) = AC`[cite: 48]
     * `ABC' + ABC = AB(C' + C) = AB`[cite: 48]
3. **Expresión Simplificada Final:**
   `F = AB + AC + BC`[cite: 48]

*Ahorro en hardware:* La versión canónica requiere circuitos integrados complejos (ej. múltiples compuertas y inversores, evaluando 4 circuitos integrados), mientras que la versión simplificada reduce drásticamente el costo físico a solo 2 circuitos integrados (`7408` y `7432`)[cite: 49, 55].
